# Work Tracker

日常記録と案件フォローのための、既存の静的ページを拡張したモジュールです。
外部ライブラリ・サーバーへのデータ送信はありません。

## 使い方

- 「記録・案件を追加」で案件を登録し、必要なら最初の対応も記録します。
- 同じ案件の「対応を記録」で、日付ごとに実績と任意の作業時間を追加します。
- 五つの業務分類と詳細分類で絞り込みます。
- 週は日本時間の月曜〜日曜です。週画面にはその週に受付・対応した案件を表示します。
- 件数・時間は対応日が確認された記録のみを集計します。状態や次アクションは現在の内容です。
- 「選択週の週報メモ」で Markdown、「選択週の対応 CSV」で集計用 CSV を出力します。
  既存の別プロジェクトの週報・月報との自動接続は、この変更には含みません。

## 保存と移行

- 記録は現在のブラウザー・オリジンの `localStorage` に保存します。認証や端末間同期はありません。
- 旧キー `work_tracker_full_v2` は変更しません。初回に新キー `work_tracker_v3` へ移行します。
- 旧「実績」は日付未確認として保持します。旧案件の日付を実際の対応日とはみなしません。
  「全案件」から履歴の「日付を確認」で対応日を入力すると、その週の集計に入ります。
- `RGS・総務` や未知の旧分類は「本社施設・総務関連 / 要分類」に置き、旧分類名を残します。
- 新しい端末・URL へ移す前に、元のページで JSON バックアップを取得してください。
  旧版しか使えない場合は、旧版の「全件ダウンロード」CSV も取り込めます。
- JSON バックアップは ID、履歴、時間、分類を保持します。新しい CSV は閲覧・集計用で、復元には JSON を使います。
- 取り込みは追加方式です。同じ ID の異なる内容は上書きせず、件数を表示してスキップします。
  古いバックアップで現在の編集を戻す機能ではありません。
- 取り込み直前の全体は `work_tracker_v3_before_import` に保存します。容量不足時は取り込みを停止します。
- 保存データが破損した場合は空データで上書きせず、原本ダウンロードの画面を表示します。

## 会社資料について

この変更は業務記録モジュールの拡張です。認証・会社向けアクセス制御を追加するものではありません。
サンプルの顧客名や業務内容は配布コードから削除しています。実際の記録・バックアップをリポジトリへコミットしないでください。
過去の Git 履歴はこの変更で書き換えません。

## 確認

ビルド不要。`index.html` が `tracker-core.js` と `tracker-app.js` を読み込みます。

```sh
node --check tracker-core.js
node --check tracker-app.js
node --test tests/core.test.cjs
```

データ移行、旧キー保持、保存失敗、日本時間・週境界、履歴集計、バックアップ復元、CSV、重複・競合の取り込みを確認します。
